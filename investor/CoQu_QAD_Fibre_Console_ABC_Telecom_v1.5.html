Quantum validity check · before any work is sent to a quantum computer

Criteria from the dispatch code
CriterionRule
Fits deviceevery circuit is compiled to the processor’s qubits, connections and native gates before it is submitted
Survives device noiseno hardware run without a noise-model rehearsal whose scores are not saturated (saturated = every noisy score below 5× the noise floor)
Agrees with exact simulationrank agreement of at least 0.90 between emulated-hardware scores and exact-simulation scores; a detector is cleared only if a noise-emulated configuration passes
Within quantum-time budgetestimated quantum time (0.25 s per circuit) must not exceed 85% of the account’s remaining quantum time; otherwise the job is refused
Operator sign-offevery hardware run needs explicit human sign-off
If any criterion fails, the record is scored by the exact simulation of the same model, which serves every request today. The failing criterion is shown with the record in the pipeline and the alert drill-down.
